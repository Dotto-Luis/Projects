PROJECT: CASITAS
Real Estate Investment Analysis Pipeline with AI-Powered Scoring
================================================================================

OVERVIEW
--------
Casitas is an end-to-end real estate investment analysis system that scrapes
residential properties from multiple Spanish real estate platforms, applies
AI-based composite scoring using a Buy Box investment criteria framework,
and generates professional bilingual investment reports (English + Spanish).

The project was built to help a family searching for a home in Málaga, Spain.
They were sharing listings in a WhatsApp group and comparing them by hand, which
was taking weeks. The pipeline analyzed 136 properties and identified 102 viable
targets classified into three tiers: Strong Opportunities, Worth Visit, Price Only.

OBJECTIVE
---------
Provide institutional-grade investment analysis by:
1. Aggregating property listings from 7 real estate platforms
2. Applying composite AI scoring based on investment criteria
3. Generating actionable investment recommendations
4. Delivering professional bilingual reports with data visualizations

KEY FEATURES
------------
1. Multi-Source Web Scraping
   - Idealista (largest Spanish platform)
   - Fotocasa
   - Pisos.com
   - YaEncontre
   - Tecnocasa
   - Habitaclia
   - Custom data enrichment from multiple sources

2. LLM-Based Property Scoring
   - Local inference using Ollama + Mistral 7B model
   - Composite scoring framework: Location (25%), Condition (25%),
     Distribution (20%), Financial (20%), Intangibles (10%)
   - Classification into tiers:
     * Strong Opportunity (85-100): Excellent fundamentals
     * Worth Visit (70-84): Good potential, in-situ verification needed
     * Price Only (60-69): Marginal, negotiation-dependent
     * Discard (<60): Poor fundamentals

3. Professional Report Generation
   - Bilingual output (English page 1, Spanish page 3)
   - Design System: Luis Dotto Portfolio (Apple-inspired minimalism)
   - 4 data visualizations with pastel traffic-light color scheme:
     * Pie chart: Recommendation distribution
     * Box plot: Price ranges by opportunity tier
     * Histogram: EUR/m² market baseline
     * Scatter plot: Score vs Price ranking (97 properties plotted)
   - Compact layout: 2 pages per language (4 total)
   - Language indicators (top-right, subtle)
   - Top 5 opportunities table with explanations

DATA PIPELINE STAGES
--------------------
Stage 1: Raw Scraping
  Input: Live web platforms
  Output: data/raw/ (HTML, JSON per platform)
  Scripts: src/scraper_*.py

Stage 2: Interim Processing
  Input: data/raw/
  Output: data/interim/combined_raw_YYYYMMDD.csv
  Tasks: Combine sources, standardize columns, normalize text

Stage 3: Processed (Ready for Scoring)
  Input: data/interim/
  Output: data/processed/activos_YYYYMMDD.csv
  Tasks: Deduplicate, enrich location, clean prices, normalize m²
  Spanish column names (required for scraper compatibility):
    url, titulo, ubicacion, precio, m2, habitaciones, baños,
    planta, ascensor, tipo, estado, año, comentario, plataforma

Stage 4: Scoring
  Input: data/processed/
  Output: data/output/ranking_final_YYYYMMDD.csv
  Process: LLM evaluation via Ollama (Mistral 7B)
  New columns: score_total (0-100), recommendation (category)

Stage 5: Visualization
  Input: data/output/ranking_final_YYYYMMDD.csv
  Output: data/output/graphic_*.png (4 charts)

Stage 6: Report Generation
  Input: ranking_final_*.csv + graphics
  Output: data/output/report_casitas_YYYYMMDD.pdf
  Format: 4-page bilingual PDF

COLUMN NAMING CONVENTION
------------------------
Spanish names maintained throughout pipeline (scraper compatibility):
  titulo: Property title/description
  ubicacion: Address/location
  precio: Price in EUR
  m2: Square meters
  habitaciones: Bedrooms
  baños: Bathrooms
  planta: Floor level
  ascensor: Elevator (yes/no)
  tipo: Property type (apartment, house, etc)
  estado: Condition (reforma, buen estado, etc)
  año: Year built/renovated
  comentario: Additional notes
  plataforma: Source platform

Post-scoring additions:
  score_total: Composite score (0-100)
  recommendation: Category (strong_opportunity, worth_visit, price_only, discard)
  precio_por_m2: Computed price per sqm

USAGE INSTRUCTIONS
------------------
Prerequisites:
  1. Python 3.10+
  2. uv package manager (pip install uv)
  3. Ollama running locally (ollama serve)
  4. Mistral 7B model pulled (ollama pull mistral)

Installation:
  1. Clone repo: git clone <repo-url>
  2. cd casitas
  3. uv sync (install dependencies)

Running the Pipeline:
  1. Execute scrapers (in order):
     uv run python src/scraper_idealista.py
     uv run python src/scraper_fotocasa.py
     (repeat for other platforms)

  2. Run scoring:
     uv run python src/scoring.py

  3. Generate visualizations:
     uv run python src/generate_graphics.py

  4. Generate report:
     uv run python src/generate_report.py

  Output: data/output/report_casitas_YYYYMMDD.pdf

Jupyter Notebooks (Optional - for analysis/debugging):
  uv run jupyter notebook
  Then open notebooks/ and run cells sequentially

KNOWN LIMITATIONS
-----------------
1. Buy Box not injected into the prompt (published run):
   The criteria document is loaded but the scoring prompt used generic tier
   descriptions instead of the real zone/price thresholds. score_property()
   now accepts a `buy_box` argument to enable the injection; re-running with
   it should sharpen the scores.

2. Coarse score distribution:
   Only 15 distinct scores across 102 properties (range 58-85), clustering at
   tier boundaries — a direct symptom of limitation #1.

3. Price parsing artifact:
   One listing is recorded at EUR 600. The cleaning stage needs an outlier
   guard for atypical price formats.
