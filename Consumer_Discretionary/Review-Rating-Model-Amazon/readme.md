## 1. Business Context
This notebook applies Natural Language Processing (NLP) to predict Amazon product review ratings (1–5 stars) based on textual content.  
It explores how language patterns correlate with customer satisfaction and product perception.

## 2. Data & Methods
Data from the **Multilingual Amazon Reviews Corpus**, with complementary references from [SASRec](https://github.com/kang205/SASRec) and [UCSD Amazon Data](https://jmcauley.ucsd.edu/data/amazon/index.html).  
The workflow includes exploratory analysis, tokenization, normalization, TF-IDF vectorization, and model training using Logistic Regression and Random Forest.

## 3. Key Results
The notebook demonstrates consistent model performance across languages, achieving robust accuracy and F1-scores in multilingual review classification.
